# Building

You only need this if you hack on skill-cli itself or regenerate the catalog
from your own skill library. Normal use needs none of it.

## Quick checks (no skill library needed)

```sh
npm test              # 76 tests, fixtures only — the CI gate
npm run sanity-check  # validates the committed catalog + core-pack license gate
```

## Full regeneration (needs your skill library)

```sh
# point at a folder of skill directories (each with SKILL.md):
export SKILLS_DIR="/path/to/skills"   # default is author-local

node scripts/scan-licenses.mjs    # licenses.json (license + attribution)
node scripts/scan-threats.mjs     # threat report (review hits by hand)
node scripts/build-catalog.mjs    # catalog.jsonl (reads origins, core-pack, curated-top)
node scripts/taxonomy.mjs --docs  # docs/CATEGORIES.md
npm run sanity-check
```

## Origin pipeline (fetchable tier)

```sh
node scripts/scan-origins.mjs     # mine local files for origin hints
node scripts/resolve-origin.mjs   # resolve + pin origins (GitHub: 60 req/hr anon;
                                  # trees+pins cached, resumable, --offline available)
node scripts/verify-origins.mjs --all      # hash fidelity vs local copies (unmetered)
node scripts/similarity-check.mjs          # drift triage for evolved copies (unmetered)
node scripts/find-candidates.mjs           # upstream skills missing from catalog
```

Results land in `src/data/origins.json` (+ verification/similarity/candidates).
`build-catalog` turns resolved + pinned origins into `fetchable` availability.
