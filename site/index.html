What it refuses to do

three rules, enforced in code

A skill runs with your agent's permissions. So the interesting question is not "how many skills", it is where the files came from.

The catalog is a discovery index, not a mirror. Nothing is re-hosted, nothing is silently replaced, and no skill is called "safe".

  • 7 core, offline
  • 1,423 fetchable, pinned
  • 139 index only
01

It will not re-host your work

Install downloads from the original repository at a pinned commit and verifies the file hashes. The author keeps their code; you get an exact, reproducible copy.

02

It will not fake availability

1,423 skills install from a verified origin. 139 do not, so they are labelled index only and the CLI says so instead of failing halfway through an install.

03

It will not install the offensive ones

20 pentest and red-team skills are indexed for completeness and blocked at install time, on top of the catalog flag. Two layers, by design.

02

The audit behind the catalog

measured, not estimated

The catalog was built by scanning 1,570 skill folders, resolving the origin of 1,521 of them, and checking every license it could find. Not by scraping a search page.

Some of what came back is worth knowing before you install anything from the open skill ecosystem.

Figures from the catalog build on 2026-09-08, re-checked by npm run sanity-check.

Ten commands, no configuration

exit 0 ok · 2 not found · 3 conflict · 4 blocked
CommandWhat it does
skill-cli search <query>Ranked search across the catalog, offline, about 20 ms.
skill-cli top [n]The curated best-of list. 106 entries, hand-checked notes.
skill-cli view <name>License, origin pin, risk flag, token count, availability.
skill-cli install <name>Core skills copy locally. Fetchable skills download from the pinned commit.
skill-cli install <name> --minimalBETA. Copy only SKILL.md, skip bundled examples and assets, report what was skipped.
skill-cli uninstall <name>Removes the skill, and asks first if you edited any files.
skill-cli list --category XBrowse by category, source tool or tier.
skill-cli statsCatalog health: records, tiers, licenses, availability.
skill-cli doctorValidates the catalog and every detected agent folder.
skill-cli request <name>Opens an issue asking for an index-only skill to gain a verified source.

Try it without installing it.

One command runs the CLI straight from npm. Keep it if you like it. MIT licensed, and the catalog lives in the repo.

Run once
npx skill-cli-ai top 10
Keep it
npm i -g skill-cli-ai
Then
skill-cli search "voice ai"

Node 18+. Windows, macOS, Linux. The 7 core skills install offline.
